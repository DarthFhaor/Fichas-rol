Propósito, obstáculo y objetivos

Objetivos

Notas

Diario de campaña

Crea una entrada por sesión, añade tus notas y adjunta imágenes a cada entrada. Todo se guarda en este navegador y se incluye en las copias JSON.

Personajes de la aventura

Organiza a tus compañeros y a los personajes que vayas conociendo. Pulsa las imágenes para ampliarlas; pliega las fichas para ver solo el retrato y el nombre. Arrastra una ficha por el control ↕ hasta otro apartado o usa «Mover a» dentro de la ficha.

Al importar se añaden personajes y apartados sin borrar los que ya tengas.

Reglas y referencias del manual

Guarda reglas, aclaraciones y extractos breves para consultar durante las partidas. Añade texto con formato, fotografías y archivos PDF de las secciones del manual. Para PDF grandes, conviene dividirlos en secciones pequeñas y exportar copias de seguridad.

Perfiles de fichas

Cada perfil es una ficha independiente en este navegador. Puedes cambiar entre ellos, crear otros nuevos o duplicar la ficha actual. Exporta copias JSON periódicamente para conservarlas fuera del navegador.

Copias de seguridad

Importar, exportar y restaurar están separados del resto de la ficha para evitar acciones accidentales. Los cambios se guardan automáticamente en este navegador. Exporta copias periódicas, especialmente si adjuntas imágenes.

Edición general

Activa este modo para renombrar títulos y etiquetas de los apartados directamente desde sus pestañas. Los valores y la información del personaje siguen siendo editables normalmente.

Sincronización con Google Drive (v12)

Después de configurarlo una sola vez, el navegador leerá y guardará tus perfiles en un archivo privado de Drive. Conserva tus copias JSON manuales por seguridad. Se necesita abrir esta ficha desde una web HTTPS; no funciona la conexión a Google desde un archivo local file://.

Abrir Drive ↗

Sin conexión a Drive. Tus datos se siguen guardando en este navegador.

Se crea un único archivo «mistborn-perfiles-sync-v12.json» para todos los perfiles. En un nuevo dispositivo, usa el mismo ID de cliente y la misma cuenta Google. Si los dos dispositivos modifican la ficha al mismo tiempo, la sincronización se detiene para evitar una sobrescritura inadvertida.
